# Шаг 0. Разворачиваем сервер-"эхо" и смотрим, что присылает amoMessenger

Ничего сложного тут нет — 4 действия, каждое через браузер, без установки программ.

## Действие 1. Разместить код на GitHub (просто как хранилище файлов)

1. Зайдите на https://github.com и создайте бесплатный аккаунт (если ещё нет).
2. Нажмите "+" в правом верхнем углу → "New repository".
3. Назовите репозиторий, например `amobot`. Оставьте "Public". Нажмите "Create repository".
4. На открывшейся странице нажмите ссылку "uploading an existing file".
5. Перетащите туда все 3 файла из этого набора: `server.js`, `package.json`, `README.md`.
6. Нажмите зелёную кнопку "Commit changes".

## Действие 2. Развернуть сервер на Render (бесплатно, без карты)

1. Зайдите на https://render.com и зарегистрируйтесь через GitHub-аккаунт (кнопка "Sign up with GitHub") — это свяжет аккаунты автоматически.
2. Нажмите "New" → "Web Service".
3. Выберите репозиторий `amobot`, который вы создали.
4. В настройках оставьте всё по умолчанию, только проверьте:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. Нажмите "Create Web Service" и подождите 2–3 минуты, пока идёт установка (внизу будет бежать лог, дождитесь надписи "Live" зелёным).
6. Наверху страницы будет ссылка вида `https://amobot-xxxx.onrender.com` — это адрес вашего сервера. Скопируйте его.

**Важно:** на бесплатном тарифе Render сервер "засыпает" после 15 минут без обращений и просыпается 30–60 секунд при следующем запросе. Для теста это не страшно.

## Действие 3. Проверить, что сервер работает

Откройте в браузере `https://ваш-адрес.onrender.com/` — должна появиться надпись:
`OK. Сервер бота запущен и работает.`

Если появилась — сервер готов принимать запросы.

## Действие 4. Подключить адрес в кабинете amoMessenger

Адрес для вебхука:
```
https://ваш-адрес.onrender.com/webhook/amomessenger
```

Зайдите в кабинет разработчика amoMessenger (developers.amo.tm), в настройках вашего бота/интеграции найдите поле для webhook URL и вставьте туда этот адрес.

**Здесь у меня нет 100% уверенности, как именно называется это поле в интерфейсе конструктора ботов** — в открытой документации amoMessenger это описано скупо, и я не хочу гадать, а потом присылать вам неверные шаги. Пожалуйста, зайдите в раздел настройки вашего бота и пришлите мне скриншот того, что видите (какие поля есть для указания адреса/URL) — я сразу скажу, куда именно вставить ссылку.

## Действие 5. Проверка

1. В amoMessenger, как вы описали: раздел "Боты" → "Создать заявку" → выбрать бота.
2. Если на этом шаге или дальше бот должен что-то прислать вам в ответ — нажмите там всё, что можно нажать.
3. Затем откройте в браузере:
   ```
   https://ваш-адрес.onrender.com/debug/last
   ```
   Там появится JSON с тем, что реально прислал amoMessenger. Скопируйте это и пришлите мне.
